# Dépôt Kodi de GuiZmY

Dépôt d'extensions pour Kodi, servi directement depuis GitHub — aucune
authentification nécessaire.

## Installation

Dans Kodi : **Extensions → Installer depuis un fichier zip**, puis l'URL du zip
de `repository.guizmy` ci-dessous. *Sources inconnues* doit être activé dans
**Système → Extensions**.

## Historique

Ce dépôt est un **artefact de publication**, pas un historique de travail. Chaque
publication le remplace par un commit unique, sans quoi chaque version du skin —
64 Mo — resterait indéfiniment dans l'historique Git.

Ne pas y commiter à la main : la propriété serait détruite au premier commit
ordinaire.

Publié par `kodi/scripts/publier-depot.sh`.
