# GuiZmY's Kodi repository

Kodi add-ons, including the Arctic Fuse X skin.

## Installation

1. In Kodi, enable **Settings → System → Add-ons → Unknown sources**.
2. Download the `repository.guizmy` zip from the folder of the same name above.
3. **Add-ons → Install from zip file**, then pick the downloaded zip.
4. The add-ons are then listed under **Install from repository**.
